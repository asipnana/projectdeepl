# Deep Learning Project

Modular deep learning project for MNIST experiments.

## Structure

- `src/` contains data loading, utilities, metrics, visualization, and model implementations.
- `checkpoints/` stores model weights.
- `results/` stores figures and metric logs.
- `data/` stores raw MNIST data.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
